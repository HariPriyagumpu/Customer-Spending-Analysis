# Customer-Spending-Analysis
Customer spending analysis using Python, Pandas and Matplotlib

📌 Project Overview

This project analyzes customer purchasing behavior to identify spending patterns and meaningful customer insights.

The analysis focuses on factors such as state, gender, age group, occupation, marital status, and product categories to understand customer spending behavior.

🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook / Google Colab

🔍 Key Analysis

- Analyzed customer spending patterns across different states
- Compared spending based on gender and age groups
- Studied customer behavior based on occupation and marital status
- Analyzed sales across different product categories
- Identified customer segments and spending patterns
- Created visualizations to make the insights easier to understand

📊 Data Analysis

The project uses Pandas for data cleaning, manipulation, grouping, and analysis.

Matplotlib was used to create charts and visualize customer spending patterns.

📈 Project Insights

The analysis helps understand:

- Which customer groups contribute more to spending
- Spending differences across demographic groups
- Popular product categories
- Customer purchasing patterns
- Potential customer segments
